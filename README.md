# EURO | اليورو

نسخة تجريبية لعرض واجهة موقع اليورو فقط، بدون قاعدة بيانات أو تسجيل دخول حقيقي.

## التشغيل على Render
- نوع الخدمة: Web Service
- Runtime: Node
- Build Command: `npm install && npm run build`
- Start Command: `npm start`
- Node Version: 20

لا تحتاج هذه النسخة إلى متغيرات Supabase أو إعداد قاعدة بيانات. المنتجات والأرصدة والإحالات المعروضة بيانات تجريبية ثابتة، ونماذج الدخول والتسجيل لا تنشئ حسابات ولا تحفظ المعلومات.

## لاحقًا
عند الجاهزية لإضافة قاعدة البيانات، يمكن إعادة ربط Supabase وتفعيل تسجيل الدخول والمنتجات والطلبات والعمولات الحقيقية.
